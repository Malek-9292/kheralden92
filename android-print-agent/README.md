# Fatoosh Android Print Agent

تطبيق Android مستقل يعمل في الخلفية لسحب مهام الطباعة من نظام فتوش وإرسالها إلى طابعة USB متوافقة مع ESC/POS (المستهدف: Epson TM-T20).

## البناء
1. افتح مجلد `android-print-agent` في Android Studio حديث.
2. استخدم JDK 17 وAndroid SDK Platform 35.
3. نفّذ Gradle Sync.
4. شغّل Build > Build APK(s)، أو نفّذ:
   `gradle :app:assembleDebug`
5. ملف APK الناتج يظهر في:
   `app/build/outputs/apk/debug/app-debug.apk`

يوجد GitHub Actions workflow لبناء APK عند تعديل ملفات هذا المجلد، ويرفع ملف debug APK كـ Artifact باسم `fatoosh-print-agent-debug-apk` لمدة 14 يومًا. افتح تشغيل Android Print Agent الناجح في تبويب Actions ثم نزّل الـ Artifact. هذا APK للتجربة فقط، وليس إصدارًا موقّعًا للنشر. لا يوجد APK مثبت تلقائيًا على جهاز المطعم.

## الإعداد
1. من لوحة إدارة فتوش افتح `/admin/printers`.
2. سجّل طابعة جديدة باسم Epson TM-T20، الاستخدام «تذاكر المطبخ»، الاتصال USB، والكود `KITCHEN-01`.
3. انسخ رمز الجهاز الذي يظهر مرة واحدة.
4. ثبّت التطبيق على جهاز Android المتصل بالطابعة عبر USB OTG.
5. أدخل رابط HTTPS للنظام، كود الطابعة، ورمز الجهاز، ثم اضغط حفظ وتشغيل.
6. وافق على صلاحية USB، واسمح للتطبيق بالعمل في الخلفية من إعدادات البطارية على الأجهزة التي تقيّد التطبيقات.

رمز الجهاز يُشفّر باستخدام Android Keystore، ولا يُكتب في Logcat.

## مسار USB على الأجهزة اللوحية الصينية
كثير من أجهزة المطابخ الرخيصة (Android Go / رومات OEM صينية) تحتاج خطوات إضافية قبل أن يعمل USB Host مع Epson TM-T20:

1. **الكابل**: USB-A (من الطابعة) → محوّل OTG USB-C مباشر. تجنّب موزّعات (hubs) الرخيصة وكابلات الشحن فقط.
2. **تفعيل OTG/USB Host**: إن وُجد خيار في الإعدادات أو Engineer Mode ففعّله، ثم أعد تشغيل الجهاز.
3. **إذن USB الدائم**: عند أول توصيل وافق على الوصول، واختر «استخدام دائمًا» إن ظهر. التطبيق يسجّل `USB_DEVICE_ATTACHED` عبر `usb_device_filter.xml` (Epson VID `0x04b8` + فئة الطابعات).
4. **البطارية والتشغيل الذاتي**:
   - Battery optimization → Unrestricted / لا تحسينات لهذا التطبيق.
   - Xiaomi/MIUI: Autostart + قفل التطبيق في Recent.
   - Oppo/Realme/Vivo/ColorOS: Allow background activity + Autostart.
   - Huawei/Honor: App launch → Manage manually (Auto-launch + Secondary + Run in background).
5. **اختبار محلي**: افتح التطبيق → «اختبار الطابعة الآن» قبل تفعيل سحب المهام من الخادم. يجب أن تخرج صفحة عربية مع قص الورق.
6. **إن لم تُكتشف الطابعة**: افصل USB 5 ثوانٍ، أعد التوصيل، تأكد أن VID يظهر في حالة التطبيق، ثم أعد المحاولة. إن ظهر جهاز USB بلا Bulk OUT فجرّب منفذًا/كابلًا آخر.

دليل المالك التفصيلي: `/cursor/stores/self/docs/hardware-print-qa.md` (في متجر مشروع الوكيل؛ انسخه للمالك عند الحاجة).

## سلوك الطباعة والاعتمادية
- يفضّل واجهات USB من فئة الطابعة، مع قائمة VID معروفة كاحتياط للأجهزة التي تُبلغ عن الصنف خطأً.
- يرسم التذكرة كصورة بعرض 576 نقطة ثم يرسلها بأوامر ESC/POS؛ هذا يتيح تشكيل العربية واتجاه RTL دون الاعتماد على Code Page محدد بالطابعة.
- يفضّل حقل `payload.lines` القادم من الخادم عند وجوده.
- يدعم تذكرة المطبخ وإيصال العميل.
- **لا يؤكد complete إلا بعد نجاح الكتابة إلى USB.**
- إن نجحت الكتابة وفشل HTTP لـ complete، يخزّن معرف المهمة محليًا ويعيد الإرسال دون إعادة الطباعة (الخادم يدعم complete/fail بشكل idempotent).
- عند فشل USB قبل اكتمال الكتابة يرسل `fail` لإعادة الجدولة على الخادم (حد أقصى 5 محاولات).

## حدود الاختبار
الكود محسّن لمسار Epson TM-T20 + Android USB Host، لكن **لم يُعتمد بعد** دون اختبار عتاد فعلي (DEC-012). يلزم اختبار عرض الورق، قص الورق، العربية، البطارية، وإعادة التوصيل قبل استقبال الطلبات الحية.
