# Fatoosh Android Print Agent

تطبيق Android مستقل يعمل في الخلفية لسحب مهام الطباعة من نظام فتوش وإرسالها إلى طابعة USB متوافقة مع ESC/POS.

## البناء
1. افتح مجلد android-print-agent في Android Studio حديث.
2. استخدم JDK 17 وAndroid SDK Platform 35.
3. نفّذ Gradle Sync.
4. شغّل Build > Build APK(s)، أو نفّذ:
   gradle :app:assembleDebug
5. ملف APK الناتج يظهر في:
   app/build/outputs/apk/debug/app-debug.apk

يوجد GitHub Actions workflow لبناء APK عند تعديل ملفات هذا المجلد، ويرفع ملف debug APK كـ Artifact باسم fatoosh-print-agent-debug-apk لمدة 14 يومًا. افتح تشغيل Android Print Agent الناجح في تبويب Actions ثم نزّل الـ Artifact. هذا APK للتجربة فقط، وليس إصدارًا موقّعًا للنشر. لا يوجد APK مثبت تلقائيًا على جهاز المطعم.

## الإعداد
1. من لوحة إدارة فتوش افتح /admin/printers.
2. سجل طابعة جديدة باسم Epson TM-T20، الاستخدام «تذاكر المطبخ»، الاتصال USB، والكود KITCHEN-01.
3. انسخ رمز الجهاز الذي يظهر مرة واحدة.
4. ثبّت التطبيق على جهاز Android المتصل بالطابعة عبر USB OTG.
5. أدخل رابط HTTPS للنظام، كود الطابعة، ورمز الجهاز، ثم اضغط حفظ وتشغيل.
6. وافق على صلاحية USB، واسمح للتطبيق بالعمل في الخلفية من إعدادات البطارية على الأجهزة التي تقيّد التطبيقات.

رمز الجهاز يُشفّر باستخدام Android Keystore، ولا يُكتب في Logcat.

## الطباعة
- يستخدم التطبيق USB Host ويبحث عن واجهة USB ذات Bulk OUT endpoint.
- يرسم التذكرة كصورة بعرض 576 نقطة ثم يرسلها بأوامر ESC/POS؛ هذا يتيح تشكيل العربية واتجاه RTL دون الاعتماد على Code Page محدد بالطابعة.
- يدعم تذكرة المطبخ وإيصال العميل.
- لا يرسل تأكيد نجاح المهمة إلا بعد انتهاء الكتابة إلى USB.
- عند الفشل يبلغ الخادم لإعادة المحاولة.

## حدود الاختبار
الكود الحالي أساس أولي ولم يُختبر بعد على Epson TM-T20 أو جهاز Android صيني محدد. يلزم اختبار USB فعلي قبل استخدامه في استقبال الطلبات الحية، خصوصًا عرض الورق، قص الورق، تشكيل العربية، استهلاك البطارية، وسلوك الجهاز عند إعادة التشغيل أو انقطاع USB.
