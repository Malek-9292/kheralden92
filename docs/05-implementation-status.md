# حالة التنفيذ — الفرع الرئيسي

آخر تحديث: 23 نوفمبر 2026 (قبول برمجي نهائي — بعد PR #6)

## ما أُنجز على `main`
- Laravel 12 + Livewire 3؛ واجهات عربية RTL؛ توقيت الكويت؛ مبالغ DECIMAL(12,3) عبر `App\Support\Money`.
- الهوية والصلاحيات والفروع؛ الكتالوج (بذور القائمة، صور، خبز صمون/صاج، مكونات الصواني في التفاصيل).
- مناطق التوصيل؛ الطلبات استلام/توصيل فقط؛ تحصيل نقدي؛ طابعات ومهام طباعة + وكيل أندرويد (برمجيًا).
- واجهة عميل (منيو/سلة/طلب) + PWA shell/SW؛ تقارير مع تصدير CSV؛ إعدادات المطعم.
- أمان: رؤوس HTTP، FORCE_HTTPS اختياري، Redis cache connection، بدون كلمة مرور إدارية افتراضية.
- استجابة متعددة الأجهزة (هاتف + Windows) — شبكة المنيو، درج الإدارة RTL، جداول→بطاقات.

## مؤجّل بقرار المالك
- اختبار Epson TM-T20 الفعلي، نشر الإنتاج، شراء استضافة.
- اختبار تثبيت PWA على أجهزة حقيقية.
- المخزون / الموردون / المشتريات / المصروفات.
- وحدة العروض والكوبونات (معطّلة في `config/modules.php`).

## تحقق
- CI: `composer validate` + `pint --test` + `php artisan test`.
- لا كلمات مرور أو مفاتيح إنتاج في المستودع.
