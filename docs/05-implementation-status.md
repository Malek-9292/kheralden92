# حالة التنفيذ — فرع التأسيس

آخر تحديث: 23 نوفمبر 2026

## ما أضيف إلى الفرع
- ملفات تأسيس مشروع Laravel 12 وLivewire 3 وComposer.
- إعداد MySQL وبيئة اللغة العربية وتوقيت الكويت.
- Module Manager وملفات Service Provider أولية للوحدات.
- جداول تأسيسية للفروع والموظفين وإعدادات تفعيل الوحدات والأدوار والصلاحيات وسجل التدقيق ومحاولات الدخول والجلسات.
- مسارات فحص الصحة واختبارات تأسيسية أولية واختبار صلاحيات مرتبط بنطاق الفرع.
- وثيقة التصميم المعماري والنموذج المنطقي للبيانات وخطة التنفيذ.
- GitHub Actions للتحقق التلقائي.

## ما لم يُنفذ بعد
هذه الملفات لا تعني اكتمال النظام. لم تُنفذ بعد وظائف الأعمال الفعلية مثل إدارة الأصناف والطلبات والسلة والكاشير والورديات والطباعة والدفع والتقارير والصلاحيات التفصيلية. ملفات Service Providers الحالية هياكل فارغة مقصودة لتحديد حدود الوحدات فقط.

## التحقق
- تم تشغيل GitHub Actions عدة مرات على الفرع؛ جميع المحاولات المتاحة انتهت بالفشل داخل خطوة إعداد بيئة الـ runner (Set up job)، قبل بدء أي خطوة من خطوات المشروع. لذلك لم يبدأ Composer أو Pint أو PHPUnit، ولا يمكن اعتبار CI ناجحًا أو اعتبار ذلك فشلًا في اختبارات التطبيق. أُضيف اختبار صلاحيات فرعية، لكنه لم يُنفذ بعد بسبب تعطل إعداد الـ runner.
- لم يتم إعلان نجاح اختبارات PHP أو Composer حتى تظهر نتيجة تنفيذ فعلية ناجحة.
- لا توجد قاعدة بيانات إنتاج متصلة بهذا الفرع، ولا يحتوي المستودع على كلمات مرور أو مفاتيح تشغيل.

## الخطوة التالية
مراجعة واعتماد SRS والتصميم المعماري والنموذج المنطقي، ثم البدء بتنفيذ وحدة الهوية والصلاحيات والفروع في Pull Request مستقل، مع اختبارات لكل وظيفة.
