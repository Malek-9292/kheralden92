# حالة التنفيذ — فرع التأسيس

آخر تحديث: 23 نوفمبر 2026 (Phase 3 كتالوج)

## ما أضيف إلى الفرع
- تأسيس Laravel 12 وLivewire 3 وMySQL 8 وComposer.
- بنية Modular Monolith وModule Manager (إعداد + اعتماديات + منع تعطيل الوحدات الأساسية + تجاوز اختياري عبر `module_settings`).
- إعداد العربية وتوقيت الكويت، وواجهة إدارة عربية RTL بلون أخضر فاتح.
- الجداول الأساسية للفروع والموظفين والوحدات والأدوار والصلاحيات وسجل التدقيق ومحاولات الدخول والجلسات وفترة صلاحية حساب الموظف وجداول Laravel للتخزين المؤقت والطوابير والجلسات.
- الكتالوج: الأقسام والأصناف والصور وفترات الظهور وسجل الأسعار، وبذور القائمة المعتمدة، وقواعد خبز الصمون/الصاج، ومكونات صواني المشويات في التفاصيل فقط.
- مناطق التوصيل، الطلبات وبنودها، التحصيل النقدي، الطابعات ومهام الطباعة.
- تسجيل دخول الموظفين برقم الهاتف وكلمة المرور، مع جلسات مسجلة ومهلة خمول وإبطال عند تغيير الحساب/كلمة المرور.
- أدوار وصلاحيات قابلة للتخصيص ومحددة بالفرع، مع قوالب أولية.
- إنشاء أول مدير نظام بأمر CLI تفاعلي دون كلمة مرور افتراضية (مع تجنّب التشفير المزدوج لكلمة المرور).
- واجهات Livewire: لوحة التحكم، الطلبات، الأقسام، الأصناف، مناطق التوصيل، الموظفون، الأدوار، الفروع، الكاشير، الطابعات.
- واجهة عميل أولية للمنيو والسلة والطلب (استلام/توصيل فقط) مع manifest وservice worker مبدئيين.
- حسابات مالية بالـ DECIMAL(12,3) وحسابات الخادم بفلوس صحيحة عبر `App\Support\Money`.
- اختبارات Feature للمسارات الأساسية، مع GitHub Actions على الفرع.

## ما لم يُنفذ بعد / جزئي
- Module Manager ما زال يعتمد مزوّدات وحدات فارغة؛ منطق الأعمال في `app/` إلى حين نقل الحدود.
- Redis مذكور في الإعدادات لكنه غير مفعّل افتراضيًا في `.env.example` (session/cache/queue = database).
- اختبار PWA على أجهزة فعلية، واختبار Print Agent على Epson TM-T20.
- الإشعارات والتقارير والنسخ الاحتياطي والمحتوى والكوبونات والورديات.
- المخزون والموردون والمشتريات والمصروفات خارج النطاق (مؤجّلة).

## التحقق الآلي
- الفرع `implementation/foundation-v1`؛ لا يُدمج إلى `main` تلقائيًا.
- CI: `composer validate` + `pint --test` + `php artisan test` داخل حاوية PHP 8.3.
- لا توجد قاعدة بيانات إنتاج متصلة بهذا الفرع، ولا يحتوي المستودع على كلمات مرور أو مفاتيح تشغيل.

## الخطوة التالية
تعزيز التوصيل/الدفع (Phase 4) ثم الطلبات والكاشير والطباعة وPWA والتقارير وجاهزية الإنتاج، مع نجاح CI قبل كل دمج إلى `main`.
