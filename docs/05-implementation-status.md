# حالة التنفيذ — فرع التأسيس

آخر تحديث: 23 نوفمبر 2026

## ما أضيف إلى الفرع
- تأسيس Laravel 12 وLivewire 3 وMySQL 8 وComposer.
- بنية Modular Monolith وModule Manager مع 21 وحدة معرفة في ملف الإعداد.
- إعداد العربية وتوقيت الكويت.
- الجداول الأساسية للفروع والموظفين والوحدات والأدوار والصلاحيات وسجل التدقيق ومحاولات الدخول والجلسات وفترة صلاحية حساب الموظف وجداول Laravel للتخزين المؤقت والطوابير والجلسات.
- تسجيل دخول الموظفين برقم الهاتف وكلمة المرور، وتسجيل الدخول والخروج ومحاولات الدخول.
- رفض الحسابات الموقوفة أو خارج فترة صلاحيتها.
- جلسات موظفين مسجلة مع إنهاء الجلسات المسحوبة، ومهلة خمول مستقلة قابلة للضبط للإدارة والكاشير.
- أدوار وصلاحيات قابلة للتخصيص ومحددة بالفرع، مع قوالب أولية: مدير النظام الرئيسي، مدير الفرع، مدير تشغيل، مدير محتوى، كاشير، مشرف وردية.
- إنشاء أول مدير نظام بأمر CLI تفاعلي دون كلمة مرور افتراضية.
- واجهات أولية لإدارة الموظفين والأدوار، مع سجل تدقيق لإنشاء وتعديل الموظفين والأدوار.
- وثائق SRS والمعمارية والنموذج المنطقي وخطة التنفيذ.
- اختبارات Feature للمصادقة والجلسات وعزل الفروع وإدارة الموظفين.
- GitHub Actions للتحقق باستخدام حاوية PHP.

## ما لم يُنفذ بعد
- واجهة رسومية مكتملة للوحة الإدارة والكاشير وموقع العميل.
- إدارة الفروع من الواجهة.
- الكتالوج: الأقسام والأقسام الفرعية والأصناف والصور والإضافات وفترات الظهور اليومية.
- السلة والطلبات والتوصيل والكوبونات.
- الورديات والتحصيل النقدي والمطبخ والطباعة وPrint Agent.
- الإشعارات والتقارير اليدوية والنسخ الاحتياطي التشغيلي والتكاملات.
- اختبارات الطباعة الفعلية على Epson TM-T20 وجهاز Android المستهدف.

## التحقق الآلي
- تم تحديد مشكلتين في إعداد CI وإصلاحهما: عدم توفر Action إعداد PHP في بيئة GitHub، وغياب مجلدات Laravel القابلة للكتابة.
- تشغيل CI الحالي وصل إلى تثبيت Composer بعد نجاح إعداد الحاوية وPHP، لكن يجب انتظار انتهاء خطوات التحقق وPHPUnit قبل إعلان نجاح الاختبارات.
- لا توجد قاعدة بيانات إنتاج متصلة بهذا الفرع، ولا يحتوي المستودع على كلمات مرور أو مفاتيح تشغيل.

## الخطوة التالية
استكمال اختبارات المصادقة والصلاحيات وإدارة الموظفين، ثم بدء وحدة الكتالوج (الأقسام والأصناف والصور) بعقود واضحة واختبارات مستقلة. لا يتم الدمج إلى main أو النشر للإنتاج قبل نجاح CI ومراجعة المالك.
