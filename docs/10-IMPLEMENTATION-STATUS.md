## الحالة الحالية

- المستودع: \`Malek-9292/kheralden92\`
- فرع التنفيذ: \`implementation/foundation\`

- المعمارية: Modular Monolith.

## الدفعة الأولى المنفذة

1. تأسيس هيكل تطبيق Laravel ونقاط الدخول والإعدادات.
2. إعداد Livewire 4 وVite.
3. ضبط اللغة الافتراضية العربية والمنطقة الزمنية Asia/Kuwait.
4. إعداد MySQL وRedis للتطوير المحلي عبر Docker Compose، دون أي بيانات اعتماد إنتاج.
5. إنشاء جدول الفرع الأول وتهيئة فرع «فتوش الخالدية» كفرع افتراضي وحيد.
6. إنشاء سجل الوحدات وخدمة Module Manager الأولية، مع فحص الاعتماديات ومنع تعطيل الوحدات الأساسية أو وحدة تعتمد عليها وحدات مفعلة.
7. إعداد اختبارات PHPUnit وGitHub Actions لبناء الواجهة وتشغيل الاختبارات.
8. إنشاء صفحة تأسيسية عربية ونقطة فحص صحة التطبيق.

## التحقق

- Composer manifest validation: ناجح.
- تثبيت اعتمادات PHP: ناجح في GitHub Actions.
- تثبيت اعتمادات الواجهة وبناء Vite: ناجح.
- تشغيل الاختبارات الآلية: ناجح في آخر تشغيل موثق؛ يجري توسيع تغطية Module Manager.
- لم يتم بعد تشغيل التطبيق على خادم أو قاعدة بيانات إنتاج.
- لم يتم شراء استضافة أو نطاق أو إنشاء أسرار إنتاج.

## حدود النطاق المحفوظة

المخزون والموردون والمشتريات والمصروفات مؤجلة. لا يوجد اتصال أو ترحيل أو اعتماد على أي مشروع قديم. لا يتم دمج هذا الفرع إلى \`main\` أو نشره للإنتاج قبل مراجعة المالك واعتماد النشر.
