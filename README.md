# فتوش | Fatoosh Restaurant System

المستودع الرسمي لتوثيق وتطوير نظام إدارة وتشغيل مطعم فتوش الجديد.

## قواعد المشروع
- هذا المشروع مستقل تمامًا عن أي نظام أو مستودع سابق.
- لا يتم تعديل أو نسخ ملفات المشروع القديم إلى هنا دون موافقة صريحة.
- يبدأ العمل بالتوثيق والاعتماد قبل كتابة أي كود.
- المنهج المعماري المستهدف: Modular Monolith.
- كل وثيقة تحمل رقمًا وإصدارًا وحالة اعتماد واضحة.

## الوثائق
- [وثيقة متطلبات النظام SRS](docs/01-SRS.md) — تُضاف بعد اعتماد الملف الأولي.

## التقنية المعتمدة مبدئيًا
- Backend: PHP + Laravel
- Database: MySQL 8
- Frontend: Laravel Livewire + Alpine.js
- Cache & Queue: Redis
- Customer App: PWA

> وجود أي متطلب في الوثائق لا يعني أنه نُفّذ برمجيًا. التنفيذ يبدأ بعد اعتماد التحليل والتصميم.
