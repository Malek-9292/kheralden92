# Modular Monolith
تُنظم كل وحدة داخل App\\Modules\\<Module> حسب Domain وApplication وInfrastructure وPresentation عند بدء تنفيذها.
التواصل بين الوحدات عبر عقود وخدمات وأحداث موثقة، وليس بالوصول إلى تفاصيلها الداخلية.
تفعيل وتعطيل الوحدات يتم عبر Module Manager وفحص الاعتماديات؛ لا تحذف مجلدات الوحدات لتعطيلها.
المخزون والموردون والمشتريات والمصروفات مؤجلة ولا تُنشأ كوحدات تشغيلية في المرحلة الحالية.
